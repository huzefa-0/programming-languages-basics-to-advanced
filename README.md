# Programming Languages: Basics to Advanced

A structured, self-paced learning repository covering major programming languages from **absolute basics to advanced topics**. Each language has its own track with the same 5-level structure, runnable examples, exercises, and a mini project.

## The 5-level structure (same in every track)

1. **01-basics** — syntax, variables, types, I/O, operators
2. **02-control-flow** — conditionals, loops, functions, error handling
3. **03-data-structures** — collections, strings, files, modules
4. **04-oop-and-patterns** — objects, interfaces/traits, generics, design patterns
5. **05-advanced** — concurrency, memory/performance, metaprogramming, testing, tooling

Each level folder contains:
- `README.md` — concepts explained with short notes
- example source files you can run directly
- `exercises.md` — practice problems (with hints)

## How to use this repo

1. Pick **one** language to start (Python or JavaScript are the friendliest).
2. Work level by level. Don't skip exercises — typing code is the learning.
3. Build the mini project at the end of the track before moving on.
4. Then learn a *contrasting* second language (e.g. Python → Go or Rust).

See [ROADMAP.md](ROADMAP.md) for suggested learning orders and timelines, and [RESOURCES.md](RESOURCES.md) for official docs and free books.
