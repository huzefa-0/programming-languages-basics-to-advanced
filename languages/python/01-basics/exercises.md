# Exercises — Python 01 Basics

Solve each in its own file. Run with `python3 yourfile.py`.

1. **Greeter** — ask for a first and last name, print `Hello, First Last!` with both capitalised. *Hint: `str.title()`.*
2. **Unit converter** — read a temperature in Celsius, print Fahrenheit to 1 decimal place. *Formula: `f = c * 9/5 + 32`.*
3. **Circle stats** — read a radius, print circumference and area using `math.pi`.
4. **Swap without a temp** — read two numbers and print them swapped. *Hint: `a, b = b, a`.*
5. **Seconds breakdown** — read total seconds, print `Hh Mm Ss`. *Hint: `divmod`.*
6. **Initials** — read a full name of any length, print the initials (`"Ada Lovelace King"` → `A.L.K.`).
7. **Rounding money** — read a price and a tax percent, print the total formatted to exactly 2 decimals.
8. **Palindrome check (single expression)** — read a word, print `True`/`False` using slicing only.
9. **Character count** — read a sentence, print total characters, characters excluding spaces, and word count.
10. **Stretch: fixed-width table** — print a 3-column table of numbers 1–5 with their squares and cubes, aligned. *Hint: f-string alignment `{x:>5}`.*
