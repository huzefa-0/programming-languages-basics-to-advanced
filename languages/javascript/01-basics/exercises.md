# Exercises — JavaScript 01 Basics

1. **Temperature converter** — function `toF(c)` returning a string like `"25°C = 77.0°F"`.
2. **Safe number parse** — `toNumber(input)` that returns a number or `null`, never `NaN`.
3. **Initials** — turn `"grace brewster hopper"` into `"G.B.H."`.
4. **Truthiness table** — log a table of 10 values and their `Boolean()` result; explain each.
5. **Coercion quiz** — predict then verify: `[] + {}`, `1 + "1" - 1`, `null == undefined`, `NaN === NaN`.
6. **Currency format** — format `1234567.891` as `"$1,234,567.89"` with `Intl.NumberFormat`.
7. **Random dice** — `roll(sides = 6)` returning a fair integer in range.
8. **Password mask** — show only the last 4 characters of a string.
9. **Optional chaining** — given a deeply nested config object, read a missing path without throwing and fall back to a default.
10. **Stretch** — write `clamp(value, min, max)` and `round(value, decimals)` and explain the float pitfalls of the latter.
