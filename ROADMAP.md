# Learning Roadmap

## Rule of thumb

> Learn one language deeply, then learn others for their ideas — not their syntax.

## Path A — Web developer

1. HTML/CSS fundamentals (outside this repo)
2. **JavaScript** levels 1–5
3. **TypeScript** levels 1–5
4. **SQL** levels 1–4
5. Optional: **Go** or **Python** for backend services

## Path B — Data / AI

1. **Python** levels 1–5
2. **SQL** levels 1–5
3. NumPy / pandas (see `languages/python/05-advanced`)
4. Optional: **C++** for performance-critical work

## Path C — Systems / low-level

1. **C** levels 1–5
2. **C++** levels 1–5
3. **Rust** levels 1–5
4. **Bash** levels 1–3 for tooling

## Path D — Enterprise / mobile

1. **Java** levels 1–5
2. **SQL** levels 1–4
3. **C#** levels 1–5 (or Kotlin/Swift outside this repo)

## Suggested timeline per language (part-time, ~8 hrs/week)

| Level | Time |
|---|---|
| 01 Basics | 1 week |
| 02 Control flow & functions | 1–2 weeks |
| 03 Data structures | 2 weeks |
| 04 OOP & patterns | 2–3 weeks |
| 05 Advanced | 3–4 weeks |
| Mini project | 1–2 weeks |

**Total: ~10–14 weeks to solid working proficiency.**
