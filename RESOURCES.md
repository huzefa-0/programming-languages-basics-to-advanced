# Curated Free Resources

## Official documentation (always the best source)

- Python — https://docs.python.org/3/
- JavaScript (MDN) — https://developer.mozilla.org/en-US/docs/Web/JavaScript
- TypeScript — https://www.typescriptlang.org/docs/
- Java — https://docs.oracle.com/en/java/javase/
- C reference — https://en.cppreference.com/w/c
- C++ reference — https://en.cppreference.com/w/
- C# / .NET — https://learn.microsoft.com/dotnet/csharp/
- Go — https://go.dev/doc/
- Rust — https://doc.rust-lang.org/book/
- PostgreSQL (SQL) — https://www.postgresql.org/docs/
- Bash — https://www.gnu.org/software/bash/manual/

## Free books

- *Automate the Boring Stuff with Python* — automatetheboringstuff.com
- *Eloquent JavaScript* — eloquentjavascript.net
- *The Rust Programming Language* — doc.rust-lang.org/book
- *Go by Example* — gobyexample.com
- *Beej's Guide to C Programming* — beej.us/guide/bgc/
- *Learn X in Y Minutes* (syntax cheat sheets) — learnxinyminutes.com

## Practice platforms

- Exercism — mentored exercises in 60+ languages
- LeetCode / NeetCode — interview-style algorithms
- Advent of Code — yearly puzzle set, great for new languages
- Codewars — small kata, gamified
- Project Euler — math-heavy problems

## Tooling to install

| Language | Toolchain |
|---|---|
| Python | `python3`, `pip`, `venv`, `ruff`, `pytest` |
| JS/TS | `node`, `npm`, `tsc`, `vitest`, `eslint`, `prettier` |
| Java | JDK 21+, Maven or Gradle, JUnit |
| C/C++ | `gcc`/`clang`, `make`, `cmake`, `gdb`, `valgrind` |
| C# | .NET SDK 8+, `dotnet` CLI |
| Go | `go` (built-in test, fmt, vet) |
| Rust | `rustup`, `cargo`, `clippy`, `rustfmt` |
| SQL | PostgreSQL or SQLite |
